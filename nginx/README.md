# Nginx

Единая HTTP-точка входа для приложения. Сервис раздаёт сборку
[фронтенда](../frontend/README.md) из тома `frontend_static`, возвращает
`index.html` для клиентских маршрутов и проксирует `/api/*` в
[backend](../backend/README.md) на порт 8080. Правила находятся в
[default.conf](default.conf).

`make up` из корня проекта собирает фронтенд и поднимает nginx. Снаружи по
умолчанию доступен порт 80. Его можно изменить через `NGINX_PORT` в `.env`.
