# PostgreSQL и миграции

`postgres` хранит пользователей, сессии, документы, историю чата и тестовые
заявки в томе `postgres_data`. Расширение pgvector используется для векторов
документов. Compose берёт имя базы, пользователя и пароль из `.env`.

Сервис `migrator` после готовности PostgreSQL выполняет `migrate up` и
завершается. Миграции в этой папке идут по номеру, каждый файл `*.up.sql`
применяет изменение, парный `*.down.sql` его откатывает.

`make seed` из корня поднимает PostgreSQL, применяет миграции и выполняет
[seed.sql](seed.sql) с тестовыми данными. `make down` сохраняет том,
`make down-v` удаляет данные вместе с томом.
